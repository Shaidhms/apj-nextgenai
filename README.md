# APJ NextGen AI · Tools Class Guide

A step-by-step companion to the **APJ NextGen AI** class — the practical, hands-on bits.

## What's inside

A single-page interactive guide covering:

- **Foundations** — AI vs ML vs DL vs Gen AI, picking the right assistant
- **Perplexity** — sign up, three modes (Search, Deep Research, Learn), Deep Research walk-through, Perplexity vs ChatGPT
- **Gemini · Music** — open Gemini, Tools → Create music, prompt · generate · download, plans
- **Suno** — sign up, Simple vs Custom mode, generate · play · share, who owns the music
- **Claude.ai** — what is Claude, chat, Projects feature
- **Claude Code (Web)** — open `claude.com/code`, attach your resume, prompt a landing page, iterate, save as `index.html`
- **GitHub** — sign up, create a repo, upload `index.html`
- **GitHub Pages** — Settings → Pages, pick the source branch, share the live URL
- **Reference** — tool comparison cheat sheet + common mistakes + FAQs

The whole guide is one self-contained `index.html`. No build step, no dependencies — open it in any browser.

## Adding screenshots

The guide ships with **31 annotated placeholder boxes**. Each one tells you the exact filename it expects and what should be in the shot.

To replace a placeholder with a real screenshot:

1. Take the screenshot.
2. Save it into `images/` with the exact filename shown on the placeholder.
3. Refresh the page. The image swaps in automatically.

The full list of needed screenshots lives in [`SCREENSHOTS.md`](SCREENSHOTS.md).
